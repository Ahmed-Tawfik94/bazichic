# PHP Slim 3

## Prerequisites
Before setting up the project, ensure you have the following installed:

- PHP >= 7.4 (or the required version for Slim)
- Composer (PHP dependency manager)
- Web server (e.g., Apache, Nginx)
- Database (e.g., MySQL, PostgreSQL)

## Installation
Clone the repository:

```bash
git clone https://gitlab.com/mididle/bazichic.git
```
Navigate to the project directory:

```bash
cd your-project
```
Install dependencies:

Use Composer to install the necessary dependencies.

```bash
composer install
```

Environment Varibales:
create `.env` inside `bazichic`directory  and add the following keys
```bash
APP_URL = "http://localhost:8000"
APP_DEBUG = 1
APP_NAME = "bazichic"
HOST = 'localhost'
DB = 'bazichicdb'
USER = ""
PASS = ""
CHARSET = 'utf8'
```
`APP_DEBUG = 1` turning the debug on and `0`set it off
